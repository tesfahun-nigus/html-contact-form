# HTML Contact Form

A semantic HTML contact form created as a learning project to practice HTML forms, accessibility, form validation, and structured document organization.

## Project Overview

This project demonstrates how to build a basic contact form using HTML5. It allows users to provide their personal information, select a subject, write a message, choose a preferred contact method, and select topics they are interested in discussing.

The project focuses on understanding the structure and behavior of HTML forms without CSS or JavaScript.

## Features

- Full name input
- Email input with email validation
- Subject selection
- Message textarea
- Preferred contact method using radio buttons
- Discussion topics using checkboxes
- Required-field validation
- Submit button
- Reset button
- Semantic form structure
- Accessible labels and field grouping

## Technologies

- HTML5

## HTML Concepts Practiced

- Semantic HTML
- `<form>`
- `<fieldset>`
- `<legend>`
- `<label>`
- Text and email inputs
- `<select>` and `<option>`
- `<textarea>`
- Radio buttons
- Checkboxes
- `required` validation
- Submit and reset buttons
- Form `method` attribute
- Accessible form labeling

## Accessibility

The form uses basic accessibility practices including:

- Explicit labels connected to form controls
- `<fieldset>` and `<legend>` for related groups
- Meaningful form control names
- Appropriate HTML input types
- Native browser validation
